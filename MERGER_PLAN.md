# Merger plan: The Rojas Report into The Alliance for Healthcare Competition at tafhc.org

Prepared November 16, 2026, on branch `merger/plan` of the rojasreport repository. Companion files: `redirects.csv` (599 rules), `merger/inventory.csv` (628 rows), `merger/_redirects.draft`. An independent reviewer checked the conflicts table, the string counts and the redirect map on November 16; its seven findings are applied. No code has been changed. Nothing in this document touches tafhc.com, ab.tafhc.com, their DNS or their hosting.

The hardest finding first: the two sites do not disagree on much, but they disagree on the one thing a physician checks, the status of each fight. The Rojas tracker scores eight fights by rule outcome and labels a reform that happened a "loss." The Alliance tracker scores three fights by bill stage. Both are right on their own terms and wrong next to each other. Section 2.3 lists every conflict with both values. Section 3.5 proposes one tracker.

Second finding: the live Rojas pages are not written in the first person. Page templates and data on origin/main contain two first-person hits in 56 templates, both in section labels ("I · The map"). The prosecutorial first-person voice lives in the newsletter, which stays with Dutch. The conversion job is 266 branding strings, not pronouns. Section 5 has the exact counts.

Third finding: 42 legacy URLs from the old single-page CON site (the original rojasreport.com) return 404 today on the apex and 301-then-404 via conlaws.rojasreport.com. They are in the redirect map so the merger fixes them rather than inheriting them.

### 3.3 How fights and intelligence connect

The proposed model is confirmed with one change: the fight page does not pull everything, it pulls what has a tag. Each research record (driver, tracker row, state, dossier, insight, desk page) carries a `fights[]` tag from the set `site-neutral`, `340b`, `physician-ownership`, or none. A fight page renders, in order:

1. The stake and the core figure (Alliance brief, as today).
2. The Tracker rows tagged to the fight (both lanes, section 3.5).
3. Cost driver brief(s) tagged to the fight (driver I for physician ownership; IV for 340B; V for site-neutral).
4. State data tagged to the fight (for physician ownership: `/poh/states/`).
5. Dossiers tagged to the fight: the AHA and FAH pillar positions, committee members with jurisdiction, the system profiles that carry the figure.
6. Insights tagged to the fight.
7. Join band.

Price transparency, certificate of need, Stark / Anti-Kickback and the other drivers the research supports carry no fight tag. They appear under Research only and say so: "Research. The Alliance is not lobbying on this issue."

CON is 30 percent of that grade and the CON desk sits at `/con/`. The physician-ownership fight page links to `/poh/states/`. The map is research; no state page carries a lobbying call to action, only the Join band every intelligence page carries.

### 3.5 The Tracker

Lives at `/tracker/` under Research and is surfaced on `/fights/` and on each fight page. One data file replaces the two today. Each row:

| Field | Values |
|---|---|
| issue | plain name |
| fight | one of the three, or `research` |
| lane | `congress` or `agency-court` |
| stage | congress: Drafted, Introduced, Committee, Floor, Law · agency-court: Proposed, Final, In effect, In court, Vacated |
| vehicle | bill number or rule citation |

Rows 1 to 8 of the Rojas tracker and the three Alliance rows all fit this model; C4 and C5 resolve by keeping both lanes side by side (H.R. 4002 Introduced in the congress lane; the Section 6001 ban In effect since 2010 in the agency-court lane).

## Appendix B: Verification script

```python
#!/usr/bin/env python3
"""verify_redirects.py: run after launch. Reads redirects.csv, checks every 301 and the untouched hosts."""
import csv, sys, urllib.request, urllib.error
UNTOUCHED = ['https://tafhc.com/', 'https://www.tafhc.com/', 'https://ab.tafhc.com/', 'https://read.rojasreport.com/']
POST_L1 = ['https://allianceforhealthcarecompetition.com/', 'https://www.allianceforhealthcarecompetition.com/',
           'https://allianceforhealthcarecompetition.org/', 'https://www.allianceforhealthcarecompetition.org/']
class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, *a, **k): return None
opener = urllib.request.build_opener(NoRedirect)
def head(url):
    req = urllib.request.Request(url, method='GET', headers={'User-Agent': 'tafhc-redirect-check'})
    try:
        r = opener.open(req, timeout=20); return r.status, r.headers.get('Location', '')
    except urllib.error.HTTPError as e: return e.code, e.headers.get('Location', '')
    except Exception as e: return 0, str(e)
fails = []
for row in csv.DictReader(open(sys.argv[1] if len(sys.argv) > 1 else 'redirects.csv')):
    old = row['old_url']
    if old.endswith('/*'): continue
    code, loc = head(old)
    if code != 301 or loc.rstrip('/') != row['target_url'].rstrip('/'):
        fails.append((old, code, loc, row['target_url']))
for u in UNTOUCHED:
    code, loc = head(u)
    if 'tafhc.org' in loc or code not in (200, 401, 301 if u.startswith('https://www.tafhc.com') else 200):
        fails.append((u, code, loc, 'must not redirect to tafhc.org'))
if '--post-l1' in sys.argv:
    for u in POST_L1:
        code, loc = head(u)
        if code != 301 or not loc.startswith('https://tafhc.org/'):
            fails.append((u, code, loc, 'https://tafhc.org/'))
w = csv.writer(open('verify_failures.csv', 'w')); w.writerow(['url', 'status', 'location', 'expected']); w.writerows(fails)
print(f'{len(fails)} failures'); sys.exit(1 if fails else 0)
```
